# SAE-S3.A.01-S3.D.01-Gestion-Salle-entreprise-WEB
Site web permettant de gérer les réservations des salles d'une entreprises.

Le site web permet d'ajouter, modifier et supprimer les éléments suivant :
- Utilisateur (employé) / fonctionnalité propre aux administrateurs
- Réservation
- Salle

Le site web permet :
- visualiser les données stockées dans la base de donnée.
- filtrer les recherches (par périodes, par salle, par employé, par activité)
- exportation des données (employé, réservation, salle)
